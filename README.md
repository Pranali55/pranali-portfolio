# Pranali Koli — Developer Portfolio

A responsive static portfolio for a Senior .NET & Python Developer.

## Run locally

No build tools are required.

1. Open the `pranali-portfolio` folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Customize

- `index.html` — profile, projects, experience, links
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation and current year

## Deploy

The site can be deployed to GitHub Pages, AWS S3 static hosting, Netlify, or Vercel.
